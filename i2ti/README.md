# I2TI — Première version

Page HTML autonome présentant les six piliers de l’offre I2TI, avec filtres et livrables dépliables. Télécharger `index.html` et l’ouvrir dans un navigateur. Aucune dépendance externe.

Le contenu est issu des visuels fournis. Le parcours en quatre étapes est une proposition éditoriale à valider. Les indicateurs sont des axes de suivi, sans résultats chiffrés. Le logo officiel reste à intégrer.

## SharePoint

Cette maquette ne remplace pas directement une page moderne SharePoint `.aspx`. L’intégration peut passer par les composants natifs SharePoint, un composant SPFx ou un hébergement HTTPS autorisé avec le composant Incorporer, selon les règles du tenant et les besoins d’authentification.

Aucune modification de la page SharePoint n’a été effectuée. L’export sur GitHub ne configure pas GitHub Pages.
